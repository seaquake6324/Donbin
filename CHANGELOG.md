# Changelog

## 1.0.0

- Play Bilibili and YouTube video audio in a Discord voice channel.
- Control playback through slash commands and a Discord OAuth web interface.
- Keep playlists in SQLite, with separate ownership for each Discord user.
- Browse public playlists or hide them and share with selected users as viewers or editors.
- Register web users with invite codes managed by a designated administrator.
- Show Discord profile avatars and in-site notifications for sharing changes.
- Pre-resolve the next track near the end of the current track.
